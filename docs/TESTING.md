# Manual test checklist (two phones)

Both phones on the same Wi-Fi or one phone's hotspot. Disable VPN.

## Voice (every release)
- [ ] Install the APK on both phones, grant microphone + notification permission.
- [ ] Each phone shows its own IP; enter the other's IP; port 8888; tap Start.
- [ ] Hold the PTT button on A: B hears A (loudspeaker). Repeat B → A.
- [ ] Self-test shows OK.
- [ ] Screen off on B: voice still plays.

## Milestone-specific
Add the acceptance test from [ROADMAP.md](ROADMAP.md) for the milestone being released.

## Reporting
Note phone models, Android versions, network type, and the diagnostics text from the screen.
